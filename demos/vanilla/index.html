Add it to an HTML site

npm package GitHub repo

  1. Install the editor
  2. Mark sentences with data-copy. The text on the page is the default.
  3. Call mount() after paint and pass isAdmin from your session.
  4. Persist on a host you run. Clone the example Express API — it writes a JSON file. Point endpoints.copy at http://localhost:4020/api/copy. Gate PUT with your login before production. Call triggerCi() after a save if you want a rebuild.
